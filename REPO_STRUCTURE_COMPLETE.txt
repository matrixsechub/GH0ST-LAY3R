## ⚡ Initialization — Command Sequence

```bash
# Clone and enter
git clone https://github.com/matrixsechub/ghost-layer-cosmology-engine.git
cd ghost-layer-cosmology-engine

# Install
npm install

# Configure
cp .env.example .env
# Set: CODEX_SECRET, N8N_WEBHOOK_URL, CURRENT_MYTHOS_PHASE=I

# Dev run
npm run dev
# → [GLCE] Engine online — Phase I

# Test
npm run test           # Vitest — all 3 unit test files

# Build + deploy
npm run build
npx vercel --prod
```
